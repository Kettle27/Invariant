# Invariant - Graph Calculator

A Desmos-style graphing calculator built with React and Three.js.

## Features
- 2D graphing with pan and zoom
- Implicit equations (e.g. x^2 + y^2 = 25)
- 3D surface plotting
- Multiple equations with colour coding
- Hover to see coordinates on a curve

## Tech Stack
React, Vite, Three.js, HTML Canvas API
